# 배틀싸피 파이썬 랩

OT Stage 1~6 실습과 추가 학습 A~Z를 브라우저에서 풀어보는 비공식 개인 학습실입니다.

## 기능

- **실습 문제:** Stage 1~6, 독립 연습 맵 12개, 턴별 시뮬레이터와 리플레이
- **추가 학습:** A~Z 26개 과제, 104개 함수 예제, 실습에 필요한 기능으로 연결
- 과제마다 요구사항, 함수 틀, 공개 예제, 3단계 힌트, 복습 질문 제공
- 브라우저 내 Python 실행: Pyodide를 별도 Web Worker에서 구동
- 공개 예제 실행과 전체 예제 채점, 반환값 및 입력 수정 여부 검사
- 코드와 노트, 통과 진도를 브라우저에 자동 저장
- 진도 JSON 백업·복원, 코드 .py 다운로드, 채팅 검토 요청 복사
- 코드 실행 6초 제한, 실행 중지, 모바일 레이아웃과 키보드 조작
- 빌드 없이 GitHub Pages에서 제공할 수 있는 정적 HTML/CSS/JavaScript

## 시작

```sh
python serve.py
```

브라우저에서 `http://localhost:4173`을 엽니다. 파일을 직접 더블클릭하는 `file://` 실행은 fetch 및 Worker 제한으로 지원하지 않습니다. 최초 Python 실행에는 인터넷 연결이 필요합니다. 코드 실행 환경과 글꼴을 외부 CDN에서 불러오며, 글꼴 로딩이 실패하면 시스템 글꼴을 사용합니다.

## GitHub Pages

이 저장소의 기본 브랜치(`master`) 루트(`/`)를 Settings → Pages → Deploy from a branch의 게시 소스로 설정합니다. 모든 자산 경로는 상대 경로이므로 프로젝트 Pages 경로에서도 동작합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다.

## 실습 문제와 추가 학습

실습 문제는 OT 1부 수정본의 단계별 목표에 맞췄습니다. Stage 1~4는 8×8에서 기본 이동·최단 경로·물 지형·사거리 판단, Stage 5는 10×10에서 나무와 탄약, Stage 6는 16×16에서 암호 보급과 적 이동을 연습합니다. 실제 평가 맵을 복제하지 않았으며 웹 연습 별점은 별도 기준입니다. 공식 OT 기준은 각 실습에서 구분하여 표시합니다. 공식 게임 결과로 전송되지 않습니다.

시뮬레이터는 나무 파괴 후 맵을 유지하고, 체력과 포탄 소비·상한을 반영합니다. Stage 6의 적 순찰·공격 순서는 학습용으로 정의한 규칙입니다. 게임 엔진과 완전히 동일한 재현을 보장하지 않습니다. 공식 자료 원문 이미지나 평가 풀이 코드는 포함하지 않습니다.

추가 학습의 구성은 다음과 같습니다.

A~G: 좌표·이동 명령·상태 파싱. H~N: BFS·경로 복원·사격·기본 봇. O~U: 비용·체력·탄약·암호·보급. V~Z: 상태 전환·검증·팀 이동·오프라인 통합.

과제 목록에서 모든 단계를 살펴볼 수 있습니다. 공개 예제만 통과하면 완료로 기록되지 않으며, 전체 채점을 통과해야 진도가 기록됩니다. 통과한 코드를 수정하면 해당 코드의 통과 상태가 해제됩니다. 풀이를 설명할 때는 복습 노트를 쓰고 ‘검토 요청 복사’로 채팅에 제출하세요. 실시간 AI 튜터는 포함하지 않습니다.

`stages.json`에 실습 맵, `simulation.py`에 시뮬레이터, `lessons.json`에 추가 학습과 기대값, `runner.py`에 검사기가 있습니다. 추가 예제도 공개 정적 파일에 들어 있으므로 부정행위 방지용 비공개 채점 시스템은 아닙니다. 실행 환경은 본인의 학습 코드를 실행하기 위한 것이며 적대적인 코드의 보안 격리를 보장하지 않습니다.

## 실제 게임 연결

이 사이트는 독립적인 학습 예제를 제공합니다. 공식 게임, PDF 매뉴얼, 팀 ID·KEY, 원본 실행 로그는 배포하지 않습니다. 나무 파괴 비용과 보급량 등 단순화한 규칙은 각 과제에 명시되어 있습니다. 실제 배틀싸피 버전의 규칙과 통신 규약은 정식 기본 코드 및 HELP를 기준으로 다시 확인해야 합니다.

브라우저는 게임의 로컬 TCP 포트에 직접 연결하지 않습니다. Z는 저장된 상태의 리플레이 검사입니다. 작성한 함수를 .py로 내려받아 정식 Python 기본 코드의 `수신 → 상태 파싱 → 행동 선택 → 명령 전송` 흐름에 통합한 뒤, 실제 게임에서 검증하세요.

## 저장과 개인정보

로그인이나 별도 서버 없이 이 브라우저의 localStorage에 저장합니다. 기기·브라우저 간 자동 동기화는 없으며 저장소 삭제 시 진도가 사라질 수 있으므로 JSON 백업을 사용하세요. 백업은 코드와 노트를 포함하며 공개 저장소에 업로드할 필요가 없습니다. 사이트는 사용자 코드를 서버로 전송하는 채점 API를 사용하지 않습니다.

Python 실행 방식은 [Pyodide 공식 Web Worker 문서](https://pyodide.org/en/stable/usage/webworker.html)를 참고했습니다. Pyodide는 `v314.0.7`에 고정되어 있습니다.
